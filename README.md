## 🌟 Key Website Features

1. **Atmospheric Himalayan Aesthetic**:
   - Palette inspired by roasted espresso, warm amber terracotta, pine forest evergreen, and soft mountain mist.
   - Clean, modern typography using Google Fonts (*Playfair Display*, *Cinzel*, and *Plus Jakarta Sans*).

2. **Interactive Handcrafted Menu**:
   - Filterable categories: **Artisan Coffee**, **Cold Refreshers**, **Teas & Warmers**, **Mountain Comforts**, and **Bakery & Sweets**.
   - Dietary & highlight tags (Veg, Specialty, Chef Pick, Customer Favorite).
   - Instant "+ Add to Tray" interactive cart system.

3. **Direct WhatsApp Order Builder**:
   - Customers can add items to their digital tray.
   - One click compiles their selected items, quantities, and total into a pre-formatted WhatsApp message sent directly to **+91 8287201301**.

4. **Table Reservation System**:
   - Seamless booking via inline form or interactive modal dialog.
   - Allows choosing seating area (Valley View Outdoor Deck, Indoor Fireplace Lounge, or Traveler Book Nook).
   - Generates instant WhatsApp confirmation to the cafe's phone.

5. **Location & Interactive Route Guide**:
   - Direct Google Maps embed with driving time markers from Mall Road Mussoorie, Dehradun, and Jharipani Falls.
   - One-tap "Get Driving Directions" and "Call Cafe".

6. **Mobile Optimized**:
   - Floating bottom quick-action bar with one-tap Call, WhatsApp, Directions, and Tray buttons.
   - Responsive slide-out navigation and cart drawers.

7. **Zero-Dependency Architecture**:
   - Pure semantic HTML5, modern CSS3 variables/flexbox/grid, and vanilla JavaScript.
   - No build tools, Node.js, or complex setups required. Double-click to run!

## 🚀 How to Run Locally

### Option 1: Direct File Opening
Simply open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Firefox, Safari).

### Option 2: Local HTTP Server (Python)
If Python is installed on your system:
```bash
cd musafir-cafe
python -m http.server 8000
```
Then open `http://localhost:8000` in your browser.

## 📦 Deployment

This static website can be deployed in seconds with zero configuration to:
- **GitHub Pages**: Push this directory to a GitHub repository and enable Pages under Settings > Pages.
- **Vercel**: Run `vercel` or drag-and-drop the folder into the Vercel dashboard.
- **Netlify**: Drag and drop the `musafir-cafe` directory onto [Netlify Drop](https://app.netlify.com/drop).
- Any standard web hosting or cPanel public_html directory.
